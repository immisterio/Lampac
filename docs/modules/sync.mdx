Lampac NextGen синхронизирует закладки, историю просмотров и позицию воспроизведения между устройствами. Данные хранятся локально в SQLite.

В `config/base.conf` эти модули разрешены, но starter-файл `config/example.init.conf` исключает `Sync` и `TimeCode`. `SyncEvents` и `Storage` загружаются, если не ограничены отдельно.

Нативные клиенты сначала читают `/bookmark/dump` и `/timecode/dump`, затем `/changelog`. Веб-плагин Lampa остаётся на `/bookmark/list`, `/bookmark/set`, `/timecode/all` и `/timecode/add`.

<Warning>
  Если вы включите Sync, но оставите TimeCode в `SkipModules`, закладки будут синхронизироваться, а позиции воспроизведения — нет.
</Warning>

Если используете встроенный плагин (`sync: true` в `initPlugins`), отключите клиентские `bookmark.js` и `timecode.js`:

```json
{
  "LampaWeb": {
    "initPlugins": {
      "sync": true,
      "bookmark": false,
      "timecode": false
    }
  }
}
```
